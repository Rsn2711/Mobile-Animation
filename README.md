# Mobile Animation Showcase

A simple HTML/CSS demo that showcases a looping marquee of mobile app screens inside an iPhone frame. It renders multiple vertical columns that scroll in alternating directions to create a dynamic app showcase effect.

## Preview

Open `index.html` in your browser to view the animation.

## Project Structure

- `index.html` — Markup for the scrolling columns and phone frames.
- `styles.css` — Styling and animation for the marquee effect.
- `screens/` — Images used for the phone frame and sample screens.

## Usage

Open `index.html` directly in a browser, or serve the folder with any static file server.
